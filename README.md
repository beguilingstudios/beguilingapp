# iOS 12 Safe Booking & Invoicing Web App

This version deliberately removes:
- React
- Expo
- npm dependencies
- service workers
- web manifest requirements
- CSS variables
- CSS Grid dependency
- SVG app icon dependency
- newer JavaScript syntax

## Deploy to Netlify

1. Extract the ZIP.
2. Open the `BookingInvoiceWebApp-iOS12-Safe` folder.
3. Drag THIS FOLDER onto Netlify Drop.
4. Wait for deployment.
5. Open the generated HTTPS URL on your Windows PC first.
6. Then open the same URL in Safari on the iOS 12 iPad.

Make sure `index.html` is directly inside the folder you upload, not inside another nested folder.

## Important

This is a compatibility-test build. Once it loads successfully on the iPad, the next step is connecting it to Supabase.
