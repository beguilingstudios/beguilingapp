BEGUILING STUDIOS - EMAIL + GOOGLE MAPS SETUP

1. EMAIL QUOTES
This version uses EmailJS because it can send from a static GitHub Pages website.

Create an EmailJS account:
https://www.emailjs.com/

In EmailJS:
- Add an Email Service.
- Connect the Gmail/Outlook/email address you want the quote to be sent FROM.
- Create an email template.
- Set the template recipient / "To Email" field to:
  {{to_email}}

Suggested template variables:
Client: {{client_full_name}}
Cellphone: {{client_phone}}
Venue: {{venue}}
Google Maps: {{google_maps_link}}
Quote: {{quote_title}}
Price: {{quote_price}}
Details: {{quote_details}}
Notes: {{notes}}
Reply email: {{business_email}}

Then open index.html and replace:
YOUR_EMAIL_ADDRESS
YOUR_SERVICE_ID
YOUR_TEMPLATE_ID
YOUR_PUBLIC_KEY

2. GOOGLE MAPS
Because the app must support an iPad mini 2 on iOS 12, it does not use the current
Google Maps JavaScript/Places widget. Google no longer officially supports iOS 12
with its current Maps JavaScript API.

Instead:
- The client types a venue name/address.
- "Find venue on Google Maps" opens that location in Google Maps.
- The client can optionally paste the Google Maps Share link into the app.
- The venue and Maps link are included in the emailed quote.
